🏨 App Hotel

Aplicativo desenvolvido em.NET MAUI como atividade da Agenda 13 da disciplina de Programação Mobile I. O projeto tem como objetivo aplicar conceitos de interface gráfica, navegação entre telas e vinculação de dados utilizando BindingContext.

📋 Funcionalidades
Cadastro e exibição de informações de hospedagem.
Utilização de BindingContext para comunicação entre telas.
Seleção de quantidade de hóspedes através do componente Stepper.
Escolha de datas utilizando DatePicker.
Seleção de opções através do componente Picker.
Tela Sobre com informações do desenvolvedor.
🛠️ Tecnologias Utilizadas
C#
.NET MAUI
XAML
Visual Studio 2022
📚 Conceitos Aplicados
BindingContext

Utilizado para realizar a vinculação entre os elementos visuais da interface e os dados da aplicação, facilitando a comunicação entre o front-end e a lógica de negócios.

Stepper

Componente utilizado para permitir a seleção de valores numéricos de forma incremental.

DatePicker

Componente utilizado para seleção de datas de entrada e saída da hospedagem.

Picker

Componente utilizado para selecionar opções disponíveis na aplicação
